# Screenshots

This directory is reserved for real screenshots of Sprite Cropper. No screenshots are included yet; please do not add mockups or animated GIFs as substitutes.

When contributing a screenshot, use a current build, capture a useful workflow at readable resolution, and remove private or personal data. Prefer optimized PNG or WebP files with descriptive names (for example, `crop-selection.png`). Add an entry here describing the screen and update the Screenshots section in the root README.
