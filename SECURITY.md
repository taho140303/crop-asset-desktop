# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Email [phwgthao.is@gmail.com](mailto:phwgthao.is@gmail.com) with a description of the vulnerability, steps to reproduce it, and any relevant impact. Please allow the maintainer reasonable time to investigate and coordinate a fix before public disclosure.

## Supported versions

Security reports are welcome for the latest released version of Crop Asset Desktop. During the current 0.x.x release series, the latest 0.x.x release is supported; older versions may not receive security fixes.

## Response targets

We aim to acknowledge security reports within 48 hours and target a fix within 7 days, depending on severity and complexity. We will keep the reporter informed if investigation or remediation takes longer, and coordinate disclosure before publishing details.
